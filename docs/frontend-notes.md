# Rizoura Foods Frontend Notes

This first pass focuses on a premium landing page experience before backend APIs, CMS setup, or Terraform.

## Current Scope

- React + Vite frontend scaffold
- TailwindCSS design system
- Framer Motion section animations
- Single-page homepage with anchored navigation for:
  - Home
  - About
  - Products
  - Export
  - Contact

## Next Recommended Steps

1. Install dependencies and run the app locally.
2. Replace placeholder contact details and product narratives with final brand copy.
3. Add real product packshots or art direction references.
4. Split sections into dedicated routed pages if you want a fuller marketing site before CMS integration.
5. Connect the contact form to Strapi or an Express endpoint.
